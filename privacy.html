Privacy Policy

Last updated: 24 November 2026.

The Lighthouse Ledger upload tool is a private application used only by the owner of the Lighthouse Ledger YouTube channel. It is not offered to the public.

What the tool accesses

Through the YouTube API Services, the tool uploads videos, thumbnails and captions to the owner's own channel, and reads that channel's video list and YouTube Analytics reports.

What is stored

Authorization tokens and upload logs are kept only on the owner's computer. No data is sold, shared with third parties or used for advertising. No data from other YouTube users is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool uses YouTube API Services; see the Google Privacy Policy.
